## Escalation path

1. Team member raises blocker in stand-up or chat.
2. Project manager resolves or reassigns within one working day.
3. Unresolved issues go to the product owner (scope or priority) or sponsor (schedule, resources).

## Principles

- One source of truth: Jira for tasks, GitHub for docs and code.
- Decisions are written down in the change log or sprint notes.
- Bad news is raised early, not saved for the review.
