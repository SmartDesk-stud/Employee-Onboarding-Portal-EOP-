# Employee Onboarding Portal (EOP)

A fully digital, web-based onboarding platform that lets HR assign tasks and collect documents, new hires follow a guided checklist, and managers track progress in one place.

Built as a Group 5 project in the Women Techsters Bootcamp Cohort 5.1 (TECH4DEV), Technical Project Management track. My role: Project Manager and Team Lead.

## What the portal does

- Role-based login for new hires, HR admins and managers
- Onboarding checklists and task assignment
- Digital document upload with approval workflow
- Progress dashboard and reminders
