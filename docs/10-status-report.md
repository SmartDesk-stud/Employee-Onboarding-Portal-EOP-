# Status Report Template and Sample: EOP

## Template

| Field | Content |
|---|---|
| Report period | Week N, dates |
| Overall status | Green / Amber / Red |
| Progress this period | What was completed |
| Planned next period | What is coming |
| Milestones | Status against schedule |
| Risks and issues | Top items with owner |
| Decisions needed | What the sponsor must decide |
| Metrics | Stories done, defects open, sprint burndown |
