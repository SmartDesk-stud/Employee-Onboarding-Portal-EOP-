# Project Closure Report and Lessons Learned: EOP

## 1. Project summary

The Employee Onboarding Portal was delivered as a web-based platform covering task assignment, document submission and progress tracking for new hires, HR administrators and managers. Work ran for ten weeks under a Scrum approach with five sprints.
